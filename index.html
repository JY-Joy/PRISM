PRISM

Prompt Refraction for Intricate Scene Modeling

Jen-Yuan Huang, Tong Lin, Yilun Du

Peking University, Harvard University

Abstract

While modern text-to-image (T2I) models excel at generating images from intricate prompts, they struggle to capture the key details when the inputs are descriptive paragraphs. We propose PRISM, a compositional approach that enables pre-trained T2I models to process long sequence inputs by decomposing them into semantic components.

PRISM demonstrates superior generalization, outperforming baseline models by 7.4% on prompts over 500 tokens in challenging benchmarks.

Method Overview

Instead of forcing pre-trained T2I models to process out-of-distribution long sequences, PRISM reframes long-text-to-image generation as a compositional task:

  • Decompose long prompts into semantic components using a lightweight module
  • Generate independent noise predictions for each component
  • Compose outputs using energy-based conjunction into a single image

Quick Start

# Clone the repository
git clone https://github.com/JY-Joy/PRISM.git
cd PRISM

# Install dependencies
pip install -r requirements.txt

# Run inference
python sample_pipeline.py \
  --ckpt /path/to/checkpoint \
  --prompt "Your detailed prompt here..."
